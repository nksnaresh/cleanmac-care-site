Clean Care Help

Support

Use the guidance below for common purchase, permission, and cleanup questions.

Restore a subscription

Open Clean Care Settings, select Subscription, and choose Restore Purchases. Use the same Apple Account that originally purchased the subscription.

Manage or cancel billing

Open App Store subscription settings. Apple manages charges, renewals, cancellations, storefront changes, and refunds.

Grant folder access

Clean Care uses the standard macOS folder picker. Grant your exact Home folder for scanning. When cleanup requires write access to a protected cleanup folder, the app asks you to select that specific folder separately.

Why some files cannot be removed

The Mac App Store version runs inside App Sandbox. Full Disk Access can improve visibility but does not disable sandbox write protections. Protected items remain visible with an explanation and are not counted as immediately reclaimable.

Restore a cleaned item

Open Quarantine in the app while the item still exists in macOS Trash. Finder may empty Trash earlier depending on your settings, and manually emptied Trash cannot be restored by Clean Care.

Prepare a diagnostic report

Open Settings, then Diagnostics. Review exported information before sharing it. Clean Care does not upload diagnostics automatically.

Need more help? Email nksnaresh@icloud.com. Include your macOS version and a short description of what happened. Do not send private file contents or passwords.
